 WordPress是一种使用PHP语言开发的博客平台，用户可以在支持PHP和MySQL数据库的服务器上架设属于自己的网站。也可以把 WordPress当作一个内容管理系统（CMS）来使用。WordPress是一个免费的开源项目，在GNU通用公共许可证下授权发布。

 这里我用最新的Centos 7 结合LNMP（Linux、Nginx、Mariadb、PHP）来搭建一个WEB Blog站点。如果要搭建一个属于自己的私有博客，主要分为两部分：域名、主机，和博客程序。（这里只介绍搭建过程，域名和主机可以百度搜索”阿里云翼计划“或者”腾讯云+校园“）。

 工具/原料：Linux/Nginx/ Mariadb（Mysql社区版本）/PHP/Wordpress
 方法/步骤：
 ①首先安装LAMP环境，需要用到5个包：nginx，mariadb，php，php-fpm，php-mysql，这里建议直接用YUM的方式来安装即可。
 \# yum -y install nginx mariadb php php-fpm php-mysql
 其中nginx可能在一般的yum源中没有，如图

![](/images/20160524102316871.png)

 这时候需要手动创建并编辑 /etc/yum.repos.d/nginx.repo文件，便可以安装

![](/images/20161120222542598.png)

 不同版本的linux编辑nginx.repo见官网描述，配置即可。 ![](/images/20160524102226250.png)

 ②获取最新的wordpress安装程序，解压到/var/www/html/目录下。
 获取wordpress的tar包方法如下：

![](/images/20160524102435001.png)

 然后linux执行下载命令，以及解压命令。
 \#wget
[https://cn.wordpress.org/wordpress-4.5.1-zh\_CN.tar.gz](https://cn.wordpress.org/wordpress-4.5.1-zh_CN.tar.gz)
 \#tar -zvxf wordpress-4.5.1-zh\_CN.tar.gz -C /var/www/html

 ③启动nginx，查看主进程，确认是否开启成功

![](/images/20160524102505470.png)

 登陆windows下的web查看

![](/images/20161120221950371.png)

 ④配置mariadb，主要是为wordpress创建库，以及授权一个本地登录用户

![](/images/20160524102532814.png)

 ⑤配置nginx文件，主要的部分已经勾画，开启php-fpm支持。访问网站开始安装。
 \# vim /etc/nginx/conf.d/default.conf

![](/images/20160524102607049.png)

 Centos7 中systemd启动php-fpm： #systemctl start php-fpm
 之后打开windows 下的web浏览器查看成功页面即可。
 PS:如果在点击开始安装的时候，报不能写入问题，编辑vim /etc/php-fpm.d/www.conf找到user和group，改成nginx ，重启php-fpm即可

![](/images/20160524102519328.png)
